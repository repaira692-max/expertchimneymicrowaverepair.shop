# Expert Chimney & Microwave Repair Website

Domain: https://expertchimneymicrowaverepair.shop/

## GitHub upload
1. Create/open your GitHub repository.
2. Upload `index.html`, `style.css`, and the `assets` folder.
3. Keep the image at `assets/expert-chimney-service.jpg`.
4. GitHub Pages: Settings → Pages → Deploy from branch → `main` → `/root`.
5. Custom domain: enter `expertchimneymicrowaverepair.shop`.
6. In your domain DNS, point the domain to the GitHub Pages records shown by GitHub. Do not guess DNS values; use the exact values GitHub displays for your repository.
