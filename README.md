## GitHub Pages
1. Create/open a GitHub repository.
2. Upload all files and the `assets` folder.
3. In Settings → Pages, select Deploy from branch → main → / (root).
4. Add the custom domain `expertchimneymicrowaverepair.shop`.
5. Keep the generated CNAME file if GitHub creates one.
6. In your domain DNS, point the domain to the GitHub Pages records shown by GitHub.

The booking form does not require a backend: it opens WhatsApp with the submitted details.
